## Overview

The AI Data Pipeline Design Assistant provides a RESTful API for programmatic access to pipeline design functionality. The API is built with FastAPI and follows OpenAPI standards.

### Base URL
```
http://localhost:8000
```

### API Version
```
v1
```

### Content Types
- **Request**: `application/json`
- **Response**: `application/json`

## Authentication

The API uses API keys for authentication. Set your API key in the request headers:

```
Authorization: Bearer YOUR_API_KEY
```

Alternatively, configure the API key in your environment variables:
```
ANTHROPIC_API_KEY=your_anthropic_api_key_here
```

## Error Handling

### HTTP Status Codes

| Status Code | Description |
|-------------|-------------|
| 200 | Success |
| 400 | Bad Request - Invalid input |
| 401 | Unauthorized - Invalid API key |
| 422 | Unprocessable Entity - Input validation failed |
| 429 | Too Many Requests - Rate limit exceeded |
| 500 | Internal Server Error |
| 503 | Service Unavailable - Dependency issues |

### Error Response Format

```json
{
  "error": {
    "code": "ERROR_CODE",
    "message": "Human-readable error message",
    "details": {
      "field": "Additional error details"
    },
    "timestamp": "2025-11-30T07:00:00Z",
    "request_id": "unique-request-id"
  }
}
```

### Common Error Codes

| Error Code | Description | Solution |
|------------|-------------|----------|
| `INVALID_INPUT` | Input description is empty or invalid | Provide a valid pipeline description |
| `AUTHENTICATION_FAILED` | Invalid or missing API key | Check your API key configuration |
| `LLM_SERVICE_ERROR` | LLM provider service unavailable | Check LLM provider status |
| `TIMEOUT_ERROR` | Request timed out | Try a simpler description or increase timeout |
| `RATE_LIMIT_EXCEEDED` | Too many requests | Wait and retry with exponential backoff |
| `INTERNAL_ERROR` | Unexpected server error | Contact support with request ID |

## Rate Limiting

### Limits

- **Requests per minute**: 60
- **Concurrent requests**: 10
- **Request timeout**: 300 seconds

### Rate Limit Headers

Rate limit information is provided in response headers:

```
X-RateLimit-Limit: 60
X-RateLimit-Remaining: 59
X-RateLimit-Reset: 1698765600
X-RateLimit-Request-ID: req-12345
```

### Handling Rate Limits

When you receive a 429 status code:

1. **Check the Retry-After header** for suggested wait time
2. **Implement exponential backoff** for retries
3. **Cache responses** when possible
4. **Batch requests** to reduce API calls

### Retry Strategy Example

```python
import time
import requests
from requests.adapters import HTTPAdapter
from urllib3.util.retry import Retry

def make_api_request(url, data, max_retries=3):
    session = requests.Session()
    
    retry_strategy = Retry(
        total=max_retries,
        status_forcelist=[429, 500, 502, 503, 504],
        method_whitelist=["POST"],
        backoff_factor=1
    )
    
    adapter = HTTPAdapter(max_retries=retry_strategy)
    session.mount("http://", adapter)
    session.mount("https://", adapter)
    
    try:
        response = session.post(url, json=data)
        response.raise_for_status()
        return response.json()
    except requests.exceptions.RetryError as e:
        print(f"Request failed after {max_retries} retries: {e}")
        return None
```

## SDK Examples

### Python SDK

```python
import requests
import json

class PipelineArchitectClient:
    def __init__(self, base_url="http://localhost:8000", api_key=None):
        self.base_url = base_url
        self.headers = {
            "Content-Type": "application/json"
        }
        if api_key:
            self.headers["Authorization"] = f"Bearer {api_key}"
    
    def design_pipeline(self, description):
        """Generate pipeline design from description"""
        url = f"{self.base_url}/design"
        data = {"description": description}
        
        response = requests.post(url, headers=self.headers, json=data)
        response.raise_for_status()
        return response.json()
    
    def health_check(self):
        """Check API health status"""
        url = f"{self.base_url}/health"
        response = requests.get(url, headers=self.headers)
        response.raise_for_status()
        return response.json()
    
    def get_api_info(self):
        """Get API information"""
        url = f"{self.base_url}/"
        response = requests.get(url, headers=self.headers)
        response.raise_for_status()
        return response.json()

# Usage example
client = PipelineArchitectClient(api_key="your_api_key")

description = """
I have CSV files landing in Azure Blob (~200GB/day) and want to build a 
bronze-silver-gold Delta Lake in Azure Databricks and expose curated tables 
to Power BI. Daily batch is fine, there is customer PII like email and phone.
"""

try:
    result = client.design_pipeline(description)
    print("Architecture:", result["architecture"])
    print("PySpark Code:", result["pyspark_code"])
except requests.exceptions.HTTPError as e:
    print(f"API Error: {e}")
```

### JavaScript/Node.js SDK

```javascript
class PipelineArchitectClient {
    constructor(baseURL = "http://localhost:8000", apiKey = null) {
        this.baseURL = baseURL;
        this.headers = {
            "Content-Type": "application/json"
        };
        if (apiKey) {
            this.headers["Authorization"] = `Bearer ${apiKey}`;
        }
    }

    async designPipeline(description) {
        const response = await fetch(`${this.baseURL}/design`, {
            method: "POST",
            headers: this.headers,
            body: JSON.stringify({ description })
        });

        if (!response.ok) {
            const error = await response.json();
            throw new Error(JSON.stringify(error));
        }

        return response.json();
    }

    async healthCheck() {
        const response = await fetch(`${this.baseURL}/health`, {
            headers: this.headers
        });

        if (!response.ok) {
            throw new Error(`HTTP ${response.status}`);
        }

        return response.json();
    }
}

// Usage example
const client = new PipelineArchitectClient("http://localhost:8000", "your_api_key");

const description = `
I have CSV files landing in Azure Blob (~200GB/day) and want to build a 
bronze-silver-gold Delta Lake in Azure Databricks and expose curated tables 
to Power BI. Daily batch is fine, there is customer PII like email and phone.
`;

client.designPipeline(description)
    .then(result => {
        console.log("Architecture:", result.architecture);
        console.log("PySpark Code:", result.pyspark_code);
    })
    .catch(error => {
        console.error("API Error:", error);
    });
```

### Integration Examples

#### With Stream Processing
```python
import asyncio
import aiohttp
from pipeline_architect_client import PipelineArchitectClient

async def process_stream_of_descriptions(descriptions):
    client = PipelineArchitectClient(api_key="your_api_key")
    
    async with aiohttp.ClientSession() as session:
        tasks = []
        for desc in descriptions:
            task = asyncio.create_task(
                client.design_pipeline(desc)
            )
            tasks.append(task)
        
        results = await asyncio.gather(*tasks)
        return results

# Usage
descriptions = [
    "First pipeline description",
    "Second pipeline description",
    # ... more descriptions
]

results = asyncio.run(process_stream_of_descriptions(descriptions))
```

#### With Data Validation
```python
import jsonschema
from jsonschema import validate

# Schema for validating pipeline descriptions
description_schema = {
    "type": "object",
    "properties": {
        "description": {
            "type": "string",
            "minLength": 10,
            "maxLength": 2000
        }
    },
    "required": ["description"]
}

def validate_description(description):
    try:
        validate({"description": description}, description_schema)
        return True
    except jsonschema.exceptions.ValidationError as e:
        print(f"Validation error: {e}")
        return False

# Usage
description = "Your pipeline description here"
if validate_description(description):
    result = client.design_pipeline(description)
else:
    print("Invalid description format")
```

### Metrics Collection

Track API usage metrics:

```python
import time
import statistics

class APIMetrics:
    def __init__(self):
        self.request_times = []
        self.error_count = 0
        self.success_count = 0
    
    def track_request(self, duration, success=True):
        self.request_times.append(duration)
        if success:
            self.success_count += 1
        else:
            self.error_count += 1
    
    def get_stats(self):
        return {
            "total_requests": len(self.request_times),
            "success_rate": self.success_count / len(self.request_times) if self.request_times else 0,
            "avg_response_time": statistics.mean(self.request_times) if self.request_times else 0,
            "p95_response_time": statistics.quantiles(self.request_times, n=20)[-1] if self.request_times else 0,
            "error_count": self.error_count
        }

# Usage
metrics = APIMetrics()

start_time = time.time()
try:
    result = client.design_pipeline(description)
    duration = time.time() - start_time
    metrics.track_request(duration, success=True)
except Exception as e:
    duration = time.time() - start_time
    metrics.track_request(duration, success=False)

print("API Stats:", metrics.get_stats())
```
